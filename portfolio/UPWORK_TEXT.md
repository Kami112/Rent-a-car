## 4. Door Measurement System  → `door-measurement/`

**Project title:** Door Measurement & Quotation App for Door Manufacturers

**Your role:** Full-Stack / Mobile Developer

**Project description:**
Built a site-survey app for a door manufacturing company. Surveyors record every opening on-site: width and height at several points, wall thickness, swing direction and material. The app syncs readings from a Bluetooth laser meter, attaches photos and notes, and works offline. The web dashboard draws each opening, auto-calculates leaf and frame sizes, and generates PDF quotations and production cut lists. This removed manual re-entry and reduced measurement errors.

**Skills:** Mobile App Development · React Native · Node.js · MongoDB · PDF Generation

**Your role:** Full-Stack Developer

**Project description:**
